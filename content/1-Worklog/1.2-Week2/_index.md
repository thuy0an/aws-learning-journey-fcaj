### Week 2 Objectives:

* Build foundational knowledge of Amazon EC2 and its related components.
* Understand how to monitor, scale, and back up AWS resources.
* Become familiar with essential services used to operate a system.
* Use the Console and CLI together to manage AWS resources efficiently.

### Week 2 Achievements:

* Gained an overview of AWS and its core service groups:

  * Compute: EC2, Auto Scaling, and Lightsail.
  * Networking: VPC, Application Load Balancer, and Internet Gateway.
  * Storage: EBS snapshots.
  * Management and monitoring: CloudWatch, AWS Backup, and Resource Groups.
* Set up and used AWS CLI automation:

  * Used AWS CLI for common management tasks, such as checking account configuration, working with S3, SNS, and IAM, configuring VPC networking, and launching EC2 instances.
  * Installed and configured AWS CLI with an Access Key, Secret Key, default Region, and output format.
* Learned how to organize resources and monitor systems:

  * Set up a launch template and Auto Scaling group with an Application Load Balancer, including target groups.
  * Used Amazon CloudWatch to monitor system performance through metrics, logs, alarms, and dashboards.
  * Used AWS Backup to automate backups for resources such as EBS and RDS, test restore operations, and configure Amazon SNS notifications.
