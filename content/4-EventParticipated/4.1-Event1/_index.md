# Event Report: AWS — Enterprise Cloud Architectures and Industry Application

### Event Overview

This was a knowledge-sharing session and study tour for Swinburne Vietnam students at the Amazon Web Services office. The event was organized with the **First Cloud AI Journey (FCAJ)** community and brought together students and Cloud, Data, and AI professionals.

### Event Objectives

- Provide a real-world view of cloud computing and enterprise application architecture.
- Create opportunities for peer learning and direct discussions with engineers and alumni.
- Give career guidance in a competitive technology market.
- Develop communication, small-talk, and networking skills to build professional visibility.

### Speakers

- **Nguyen Gia Hung** — Head of Solution Architects, AWS Vietnam.
- **Banh Cam Vinh** — Data Engineer at Renova Cloud and AWS Community Builder.
- **Khang Nguyen** — Solution Architect at Cloud Kinetics and Swinburne Vietnam alumnus.
- **Nhu** — Account Manager, AWS Vietnam.

### Key Highlights

#### Cloud market and career trends

- New graduates need practical skills because the technology market is increasingly competitive.
- Candidates should build projects that solve real problems in a specific industry, such as retail, fintech, or telecommunications.
- A useful formula shared at the event was: **Results = Capability × Visibility × Consistency**.
- Certificates, technical blogs, and personal project source code help show continuous learning in automated CV screening.
- A **Cloud First** approach shifts job demand toward people who can design and operate cloud-based systems.

#### Data engineering and architecture mindset

- Focus on core data-platform parts—**ingestion, processing, storage, and analytics**—instead of memorizing individual tools.
- Use AI assistants such as **Kiro**, together with AWS documentation and the **AWS Well-Architected Framework**, to review and improve projects.
- Communication with Business and Product teams is an important technical skill.
- Technology choices need clear trade-off analysis for cost, time, and operations.

#### Communication and career development

- Small talk and proactive communication help build professional visibility.
- Many workplace conflicts come from different technical and business viewpoints; it is important to understand the goal behind feedback.
- Building relationships and contributing consistently can create opportunities beyond highly competitive job applications.

#### Learning and using AI

- AI can support work, but it cannot replace understanding of the underlying concepts.
- Keep asking “why,” learn beyond basic modules, and seek practical exposure to different systems and customers.
- Consider salary, experience, network, knowledge, and personal growth when choosing a job.

### What I Learned

- Start with the business problem when designing software and data architecture.
- Design personal projects for scalability, failure handling, reliability, and security—not only to make them run.
- Use a common framework across platforms and use AI with official documentation for cross-checking.
- Follow a Cloud First approach and improve projects toward production readiness.

### Applying the Learning

- Build projects that solve problems in a specific industry.
- Develop daily professional visibility through communication and networking.
- Use AI with reliable prompts and official documentation instead of using it as a substitute for learning.
- Review projects with the AWS Well-Architected Framework.

### Event Experience

The open discussions with professionals from AWS, Cloud Kinetics, and Renova Cloud gave me a clearer view of the real technology market. I learned that strong technical skills must be combined with business understanding, communication, and a customer-focused mindset.

#### Key Takeaways

- Keep investing in learning and building practical projects.
- For new graduates, a proactive attitude and willingness to learn are especially important.
- AI is powerful, but responsible decisions require understanding and verification.
