# Event Report: FCAJ Community Day

### Event Overview

**FCAJ Community Day** was a practical sharing session organized by the **First Cloud AI Journey (FCAJ)** community. It covered the AWS Cloud Practitioner learning path, system operations such as SLA and monitoring, and security automation using security agents and penetration testing.

### Event Objectives

- Give learners clear cloud-learning milestones through certification paths.
- Build an enterprise mindset, incident-management skills, and customer-focused thinking.
- Introduce modern security tools for reviewing design documents, source code, and application endpoints.

### Speakers

- **Huy** — AWS Cloud Practitioner (CLF-C02) learning path, exam structure, and study tips.
- **Son** — HUFLIT alumnus and Infrastructure Reliability Engineer; monitoring, NOC, and SLA practices.
- **Nghia Tran** — Demonstration of a Security Agent for finding application vulnerabilities.

### Key Highlights

#### AWS Cloud Practitioner strategy

- The exam takes 90 minutes; Vietnamese candidates receive an additional 30 minutes and need 700/1000 to pass.
- The main areas are Cloud Concepts, Security and Compliance, Technology and Services, and Billing and Pricing.
- Learners should review why wrong answers are wrong, use elimination, identify keywords, and avoid overthinking.

#### NOC, SLA, and operations

- A **Network Operations Center (NOC)** monitors infrastructure 24/7.
- An **SLA** defines service commitments, including uptime. SLA breaches can cause financial and reputational loss.
- A healthy infrastructure does not always mean users have a good experience; engineers need to understand both infrastructure and application flows.

#### Security automation and mTLS

- Security Agents can integrate with GitHub or GitLab for design review, code review, and endpoint penetration testing.
- **Mutual TLS (mTLS)** requires both client and server certificate validation and is commonly used in financial systems.

### What I Learned

- Follow clear SOPs when responding to incidents and focus on solving customer problems.
- Apply the **principle of least privilege** when granting access.
- Plan for failures and maintain a backup plan.

### Applying the Learning

- Monitor more than CPU and memory: create CloudWatch alarms and SNS notifications for backend and database connectivity.
- Integrate security checks into CI/CD to detect issues such as exposed credentials.
- Review On-Demand, Reserved Instance, and Spot pricing models to optimize cloud costs.

### Event Experience

The event offered a realistic view of NOC operations and system management. Live demonstrations, including an application sign-in failure, showed why proactive monitoring and alarms are important.

#### Key Takeaways

- Technical skills need to be combined with a customer-oriented mindset.
- Team support, ownership, and collaboration are essential in a global working environment.
